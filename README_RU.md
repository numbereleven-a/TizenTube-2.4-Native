# TizenTube 2.4 Native

[English README](README.md)

Нативный YouTube-плеер со SponsorBlock для телевизоров Samsung на **Tizen 2.4**.

В отличие от стандартного [TizenTube](https://github.com/reisxd/TizenTube) и [TizenTube-old-tizen](https://github.com/numbereleven-a/TizenTube-old-tizen), это приложение **не загружает веб-интерфейс YouTube TV** и **не использует HTML `<video>` / Media Source Extensions (MSE)**. Вместо этого оно объединяет лёгкий собственный интерфейс для ТВ и нативный ARM-модуль NaCl (Pepper 42): Mbed TLS принимает HTTPS-потоки по TLS 1.3/1.2, демультиплексоры MP4/WebM извлекают пакеты в фоне с ограниченными буферами, а аппаратный плеер Samsung (`ESPlayer`) выполняет декодирование, вывод изображения и синхронизацию звука.

Приложение работает полностью автономно на телевизоре. Во время просмотра компьютер, внешний прокси и локальный сервис не нужны.

> **Поддерживаемая ОС:** поддерживается **Tizen 2.4** (ARM-телевизоры Samsung с Pepper 42 NaCl). Другие ОС и версии Tizen не тестировались. Если вам нужен стандартный HTML-интерфейс YouTube TV, см. [TizenTube-old-tizen](https://github.com/numbereleven-a/TizenTube-old-tizen) или оригинальный [TizenTube](https://github.com/reisxd/TizenTube).

## Главное отличие от стандартной HTML-версии

Стандартный [TizenTube](https://github.com/reisxd/TizenTube) и [TizenTube-old-tizen](https://github.com/numbereleven-a/TizenTube-old-tizen) открывают официальный веб-интерфейс YouTube TV внутри старого браузера WebKit на телевизоре и воспроизводят видео через JavaScript и HTML5 MSE.

**TizenTube 2.4 Native** отказывается от тяжёлого HTML-интерфейса YouTube на WebKit и использует лёгкий собственный интерфейс для ТВ вместе с нативным ARM-модулем NaCl (Mbed TLS + демультиплексоры MP4/WebM + Samsung `ESPlayer`). За счёт отказа от веб-приложения YouTube на WebKit программа быстрее запускается и заметно отзывчивее реагирует на пульт при навигации, а видеоданные остаются внутри ограниченных нативных буферов и не проходят через браузерный JS/MSE.

## Установка

В ZIP-архиве релиза находится один неподписанный `.wgt`. Перед установкой его нужно подписать профилем сертификата Samsung, в который добавлен DUID вашего телевизора. Личные сертификаты и подписи для конкретного устройства в архив не входят.

1. Скачайте ZIP-архив из [последнего релиза](https://github.com/numbereleven-a/TizenTube-2.4-Native/releases/latest) и извлеките `.wgt`. Для команды Tizen Studio CLI ниже откройте `.wgt` как ZIP и извлеките его содержимое в отдельную папку.
2. Установите Tizen Studio, Samsung TV Extension и Certificate Manager.
3. Включите Developer Mode на телевизоре, подключите ТВ и создайте профиль сертификата Samsung с DUID телевизора. См. [инструкцию по сертификатам](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/creating-certificates.html) и [подключению телевизора](https://developer.samsung.com/smarttv/develop/getting-started/using-sdk/tv-device.html).
4. Соберите и подпишите WGT своим профилем сертификата через Tizen Studio или CLI:
   ```text
   tizen package -t wgt -s YOUR_CERTIFICATE_PROFILE -o out -- распакованная_папка
   ```
5. Установите подписанный WGT на подключённый ТВ и запустите **TizenTube 2.4 Native** из меню приложений.

Приложение не распространяется через Samsung Apps. Инструкция по сборке из исходников приведена ниже.

### Обновление установленного приложения

Подписывайте обновления тем же сертификатом автора и устанавливайте поверх существующего приложения: это сохраняет аккаунты, настройки и локальные позиции продолжения. При истёкшей или отозванной авторизации может потребоваться повторный вход. Удаление приложения очищает его локальные данные.

## Возможности

- **Нативный конвейер воспроизведения:** HTTPS/TLS 1.3 и TLS 1.2 (Mbed TLS с проверкой сертификатов и имени хоста), фоновый демуксинг MP4/WebM с ограниченными буферами и аппаратное декодирование через Samsung Pepper 42 `ESPlayer`.
- **Видео и аудио:** H.264 до 1080p60 и VP9 (profile 0) до 2160p60 (4K60) со звуком AAC. Настраиваемый предпочтительный кодек и максимальное разрешение (по умолчанию: H.264 до 1080p).
- **Собственная навигация для ТВ:** боковое меню с разделами «Главная», «Поиск», «Подписки» (хронологическая лента загрузок + «Мои каналы»), «Библиотека», «История», «Смотреть позже» и «Понравившиеся», а также переход на канал из плеера («На канал»).
- **Встроенный поиск:** экранная русско-английская клавиатура с рядом цифр, подсказки поиска и прямое открытие по ссылке YouTube или ID видео.
- **Аккаунты Google:** вход по QR-коду на экране ТВ, хранение нескольких аккаунтов в закрытом хранилище телевизора, отправка истории просмотров, лайки и подписки на каналы.
- **SponsorBlock:** восемь независимо настраиваемых категорий пропуска (по умолчанию: реклама, самореклама, просьбы подписаться и поставить лайк), зелёные метки на шкале и отключаемые уведомления о пропуске.
- **Удобство просмотра:** главы автора, переход «В начало видео», субтитры YouTube JSON3, ручная смена качества во время просмотра, опциональное автовоспроизведение следующего ролика и сохранение локальных позиций продолжения для последних 100 видео.
- **Устойчивость сети:** ограниченные повторные попытки на новом соединении при сбоях медиапотоков HTTP 503/403 и обрывах TLS, а также резервное получение потоков через авторизованный клиент при входе в аккаунт.

## Управление пультом

| Кнопка | Действие |
|---|---|
| Стрелки | Навигация по меню, карточкам видео и экранной клавиатуре |
| OK (во время просмотра) | Показать шкалу без паузы; повторное нажатие OK на шкале ставит на паузу / продолжает |
| Влево / Вправо (во время просмотра) | Накопление шага перемотки за 650 мс с показом целевого времени и смещения |
| Вверх (во время просмотра) | Открыть главы автора, переходы по времени и «В начало видео» |
| Вниз (во время просмотра) | Выбор кнопок плеера (качество, субтитры, SponsorBlock, лайк, подписка, «На канал») |
| Назад | Закрыть панель/меню, затем вернуться к предыдущему списку |

Дополнительные детали управления:

- Панель плеера и её меню скрываются через 5 секунд без нажатий, в том числе на паузе.
- В настройках есть опция **«После перемотки — пауза до OK»** (выключена по умолчанию): ручная перемотка, выбор главы и «В начало видео» оставляют ролик на паузе до нажатия OK. Автопропуск SponsorBlock и возврат позиции при смене качества сохраняют обычное состояние воспроизведения.
- Смена качества во время просмотра переоткрывает нативные потоки на текущей позиции (ручной выбор качества, без адаптивного переключения битрейта). Более высокие разрешения могут автоматически переключаться с H.264 на VP9.
- В поиске нажатие «Вверх» над рядом цифр переводит фокус на подсказки; «Вниз» с последней подсказки возвращает на клавиатуру.

## Настройки, аккаунты и диагностика

- **Языки интерфейса:** русский и английский.
- **Рекомендации на главной:** можно скрыть отдельно от поиска и подписок (на рекомендации лаунчера Samsung это не влияет).
- **Аккаунты:** несколько QR-авторизаций хранятся в закрытом хранилище ТВ; refresh-сессии остаются на телевизоре, а access-токены держатся только в памяти. Добавление нового аккаунта сохраняет существующие; выход удаляет только активный аккаунт.
- **История и конфиденциальность:** отправка истории просмотров начинается через 5 секунд фактического воспроизведения и может быть поставлена на паузу в настройках. Поиск выполняется через неавторизованный клиент и не попадает в историю аккаунта. Глобальные настройки истории Google открываются по QR-коду на телефоне.
- **Сброс настроек:** требует подтверждения и удаляет все локальные аккаунты, настройки, позиции продолжения, кэш обработчика потоков и диагностику, не затрагивая историю в аккаунте Google.
- **Локальная диагностика:** в настройках доступен ограниченный локальный журнал, сохраняющийся между перезапусками. Он фиксирует числовые коды плеера и HTTP, размеры очередей, позиции воспроизведения и маркеры незавершённого закрытия. ID и названия видео, имена аккаунтов, URL потоков, токены и тела ответов в журнал не попадают; автоматической отправки данных нет.

## Требования, совместимость и ограничения

- **Поддерживаемая ОС:** поддерживается **Tizen 2.4**; проверено на **Samsung UE50KU6000** (`Tizen 2.4.0`, `T-JZL6DEUC-1260.1`). Другие ОС и версии Tizen не тестировались; совместимость со всеми моделями и прошивками Tizen 2.4 не гарантируется.
- **Поддерживаемые потоки:** только конечные VOD-ролики. Прямые трансляции (Live) не поддерживаются.
- **Исключённые форматы видео:** AV1 и HDR / VP9 profile 2 (включая старую метку `vp9.2`) исключены; для VP9 используется SDR profile 0.
- **Обработчик потоков (decipher worker):** когда авторизованным TV-потокам требуется `n`-преобразование, Web Worker обрабатывает скрипт плеера YouTube и кэширует подготовленный код на телевизоре для данной версии плеера. Первая подготовка для новой версии плеера YouTube занимает около 40 секунд на KU6000; последующие запуски используют кэш. Обычные прямые потоки не запускают воркер.
- **Длительная стабильность и изменения API:** стабильность многочасовых сеансов всё ещё требует более широкой проверки. Приватный API YouTube может меняться независимо от проекта.

## Сборка из исходников

Требования: Node.js, PowerShell, Samsung Pepper 42 ARM NaCl SDK, Mbed TLS 3.6.7, zlib 1.3.2, [yt-dlp EJS 0.8.0](https://pypi.org/project/yt-dlp-ejs/0.8.0/) (`lib.min.js` и `core.min.js`) и Tizen Studio CLI с профилем сертификата ТВ.

Передайте локальные пути к зависимостям в параметрах:

```powershell
./scripts/build-native.ps1 -SdkRoot SDK_ROOT -MbedTlsRoot MBEDTLS_ROOT -ZlibRoot ZLIB_ROOT
npm ci --ignore-scripts
node scripts/build-decipher.cjs EJS_ROOT
node --test test/player.test.js test/account.test.js test/playback-controls.test.js test/history-diagnostics.test.js test/settings.test.js test/decipher.test.js test/player-cache.test.js test/search-keyboard.test.js test/shell.test.js
./scripts/package.ps1 -TizenCli TIZEN_CLI -CertificateProfile TV_PROFILE
```

Примечания по сборке:

- Нативные библиотеки компилируются при первой сборке. Собранные пакеты сохраняются в `artifacts/<версия>/`; перед повторной упаковкой увеличьте версию в `app/config.xml`.
- Обычная сборка создаёт неподписанный ZIP с файлами виджета и WGT, подписанный вашим локальным профилем ТВ. Публиковать нужно только неподписанный ZIP; для установки на другой телевизор пакет подписывается сертификатом этого ТВ.
- Автономные тесты демультиплексоров (`test/demuxer.cc` и `test/demuxer-limits.cc`) собираются хостовым компилятором C++14 вместе с `native/src/media/*.cpp`. Материализуемые фрагменты ограничены 64 МиБ и 65 536 сэмплами на дорожку.
